# Share a prototype

1. Confirm the runnable prototype directory.
2. Use a saved preferred deployment target when it is still available; otherwise ask where to deploy.
3. Build and test locally before deployment.
4. Use the selected deployment tool directly when available.
5. Verify the returned URL in a clean browser session.
6. Return the working URL and state any manual follow-up.

Do not deploy before the user selects the target. Do not claim success until the URL loads. If the selected tool is unavailable, say so and ask whether to use another target.
